# CLAUDE.md

Project knowledge (architecture, conventions, workflows, gotchas) lives in a
searchable index of `{docs}/`, not in this file. **Search it before you explore
code or make changes**, then read only what you need:

- `{cmd} search "<keywords>"` (MCP tool: `search_docs`)
- `{cmd} read <id>`, or `<id>#<section>` for one section (MCP: `read_doc`)
- `{cmd} list` to browse everything (MCP: `list_docs`)

New here? Start with `{cmd} read start-here`.

Learned something the next agent will need? Add or update a doc in `{docs}/`
(how: `{cmd} read writing-docs`), then run `{cmd} check`.
